# عنايتي — Inayati

منصة تجارة إلكترونية لكيتات العناية الشخصية الجاهزة، مبنية على احتياج كل عميلة.
مشروع مقرر **IT473 — أنظمة التجارة الإلكترونية** · الفريق: ريناد، ريفال، رنيم.

## التشغيل

يحتاج **Node.js 22.5 أو أحدث** (قاعدة البيانات SQLite مدمجة في Node، ما تحتاج تثبيت شي ثاني).

```bash
npm install
```

```bash
npm start
```

افتحي http://localhost:3000

| للتجربة | القيمة |
|---|---|
| حساب الإدارة | `admin@inayati.sa` / `Admin@123` |
| بطاقة ناجحة | `4242 4242 4242 4242` — أي تاريخ مستقبلي وأي CVV |
| بطاقة مرفوضة | `4000 0000 0000 0002` |

- قاعدة البيانات تُنشأ تلقائياً في `data/inayati.db` مع كل المنتجات والكيتات.
- لبداية نظيفة قبل العرض: `npm run reset` ثم `npm start`.
- لإعادة توليد التقرير والعرض PDF: `npm run pdf` (يحتاج Playwright).

## سيناريو العرض الحي (5 دقائق)

1. الرئيسية ← «حددي روتينك» ← اختاري: الاثنين · لامعة بالكامل · حبوب · كيرلي · **الكحول** · 200–350.
2. وضّحي سبب الاختيار والاستبدال (واقي الشمس بالكحول ← الواقي المعدني).
3. «التفاصيل وطريقة الاستخدام» ← المستويات، الاشتراك، تبويب الروتين، **زر تيك توك**.
4. «اشتركي شهرياً» ← السلة ← إنشاء حساب ← الدفع بالبطاقة المرفوضة ثم الناجحة ← صفحة التتبع.
5. حسابي ← اشتراكي: تخطي شهر / تغيير المستوى / «حدّثي احتياجك».
6. سجلي خروج ← دخول الإدارة ← الطلبات (بدء التجهيز ← الشحن) ← الاشتراكات «محاكاة مرور شهر» ← نظرة عامة (MRR).

## هيكل المشروع

```
server.js             الخادم وكل مسارات الـ API
lib/db.js             جداول قاعدة البيانات والبيانات الأولية
public/js/data.js     المحتوى: المنتجات، الكيتات، الروتينات (مصدر البيانات الأولية)
public/js/engine.js   الأسعار + أسئلة الاختبار + قواعد التوصية (مشترك بين المتصفح والخادم)
public/js/app.js      الهيدر والفوتر والسلة ورسومات الكيت
public/*.html         الصفحات: index, quiz, kits, kit, cart, order, account, admin
public/css/style.css  نظام التصميم (الألوان والخطوط)
public/assets/        الشعار
docs/                 التقرير والعرض (HTML + PDF) ولقطات الشاشة
```

## توزيع العمل

الشرح الكامل لكل عضوة (ملفاتها، كيف تشرح جزءها، والأسئلة المتوقعة): [docs/TEAM-GUIDE.md](docs/TEAM-GUIDE.md)

| العضوة | الجزء | الملفات |
|---|---|---|
| ريناد | الهوية، المحتوى، قواعد الاختبار، الواجهات | `public/assets`, `public/css`, `public/js/data.js`, `public/*.html` |
| ريفال | قاعدة البيانات، الحسابات، لوحة الإدارة، السلة والدفع | `lib/db.js`, `server.js` (auth/orders/admin), `admin.html`, `cart.html` |
| رنيم | منطق التوصية، الاشتراك، التتبع وسجل الطلبات | `public/js/engine.js`, `server.js` (recommend/subscriptions), `order.html` |

## ملاحظات

- الدفع **تجريبي** ولا يتم خصم أي مبلغ.
- المنتجات بأسماء عامة، وروابط تيك توك تشير لحساب `@inayati.sa` — استبدليها بروابط الفيديوهات الفعلية من لوحة الإدارة.
- قواعد التوصية مبسطة ولا تغني عن استشارة طبيبة الجلدية.
